# 我的私人音乐台

直接双击 index.html 即可打开，无需安装依赖或启动服务。

- index.html：HTML5 页面结构，二十首音乐均使用 audio controls 和两种 source。
- style.css：独立样式，支持电脑和手机屏幕。
- script.js：开始收听、播放状态、切歌时暂停其他歌曲。
- assets/audio/：本地 MP3 与真实转码的 Ogg 音频，可离线播放。
- assets/images/：本地音乐盒封面。
- sources.json：每首音频与封面的来源地址。

歌曲：闪光舞、万众瞩目、EZ4ENCE、花脸、冲击星（dashstar*）、你急了！、躺平青年、就是我、迈阿密热线、CSGO 精彩时刻、好好干，好好活、追溯起源、神枪手、终极、触摸能量、非人类、通宵达旦、燥起来！、理由、令人发指。
音频使用音乐盒的 MVP 版本。万众瞩目属于 CS2 音乐盒，因此页面标记为 CS:GO / CS2。
音频来自 CS2 Items 公开试听，封面来自 Steam CDN，曲目信息参考 ByMykel/CSGO-API。素材版权归原权利人所有。
